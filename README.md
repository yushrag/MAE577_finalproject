# Simulating Swarm Robots for Space Stations
Final project for MAE577: Multi-Robot Systems: Body-Brain-Colony

This project investigates the application of biologically inspired swarm robotics algorithms within confined microgravity environments representative of the interior of future
space stations. A browser-based simulation environment was developed to model free-floating robotic agents operating inside a confined orbital habitat inspired by the TESSERAE modular
robotic architecture. The simulation utilizes local interaction laws outlined in previous swarm robotics research inspired by schools of fish.
